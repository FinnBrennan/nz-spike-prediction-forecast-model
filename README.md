# NZ Electricity Price Spike Forecasting

Forecasting model that uses hydro lake storage levels to predict wholesale
electricity spot price spike risk in New Zealand.

## Status

Planning/Early development. Not functional.

## What it will do

- ingest public EMI price and hydro data
- forecast spike risk at several time horizons
- benchmark against naive baselines and futures
- summarize findings and performance in a simple streamlit dashboard

## Setup

```bash
git clone https://github.com/FinnBrennan/nz-spike-prediction-forecast-model.git
cd nz-spike-prediction-forecast-model
uv sync
```

## Project structure
